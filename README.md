Developed and currently maintained independently, including the frontend, backend, responsive UI, multilingual support, custom contact/booking form, automated email handling, SEO, and deployment.

Custom coffee shop menu web application developed using Angular, TypeScript, HTML, CSS, Node.js, Express, Firebase, and Vercel.

Custom business website developed with WordPress and Elementor.

Custom business website developed with WordPress and Elementor.
